# 电控组第二次作业
## 实现功能
1. **第一题上次拓展部分做了，偷个懒[doge]，第二第三题整合到了拓展部分中，所有代码都在main.c文件中，此外，因为vscode的调试模式并不能显示变量值，故采样oled屏幕进行ADC接口读数和电压的显示**
2. **按键调光与模式切换**
- 此部分通过TIM3的计时器中断和PWM输出实现，时钟频率设为72MHz，PSC为720-1，ARR为1000-1，即10ms进行一次重装载，按键的消抖和小灯状态控制在中断回调函数中实现（对应代码64至111行），小灯的亮度调节和呼吸灯在主循环中实现（对应代码185至215行），对应变量可在while前找到。
3. **电位器对舵机的控制**
- 此部分通过ADC1通道读取电位器的电压，同过TIM4输出PWM对舵机进行控制，TIM4的PSC设为720-1，ARR设为2000-1，使PWM频率为50Hz，我使用的舵机为180带限位的，0至180度对应占空比为2.5%至12.5%，对应CCR值为50到250，对应的ADC值转换公式为
- *sevro_duty = (((value / 4095.0) x 10 + 2.5) / 100.0) x 2000* 
- 其中value为ADC接口读数，sevro_duty为对应CCR值
- ADC接口读数和电压值通过oled屏幕显示，oled屏的驱动库来自b站up主keysking，不得不说这驱动库真轮椅（）
- 舵机和电位器的代码位于176至183行，oled屏的代码位于217值230行
